=====================================================
OMNIDASH.BI - PORTABLE BUSINESS REPORTING SUITE
=====================================================

HOW TO USE (NO INSTALLATION REQUIRED):
1. Double-click "OmniDash_Business_Analytics_Standalone.html" to open it in Chrome, Edge, Safari, or Firefox.
2. The entire application runs 100% offline directly in your browser.
3. You can upload Excel (.xlsx, .xls), CSV, Word, PowerPoint, and PDF files.
4. Perform complex calculations, customize widgets, and export PowerPoint presentations (.pptx) or PDF reports.

OPTIONAL LOCAL AIRLLM SERVER:
If you want to connect to a local AirLLM Python server:
  pip install airllm fastapi uvicorn torch
  python airllm_server.py --model_path /path/to/model --port 8000
